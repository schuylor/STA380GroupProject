This vignette demonstrates how to use the function within the ‘STA380GroupProject’ package for simulating sample distributions with the two-sample bootstrap method:

  • two-sample bootstrap ’STA380GroupProject::two_sample_bootstrap()

The following examples are for generating 1000 bootstrap iterations to construct sampling distributions for the difference in means across two biological categories. We investigate:

  • Sexual variation: Computing mean snout-vent lengths(mm) between males and females

  • Thermoregulation: Comparing mean body temperatures (Celsius) between gravid and non-gravid females

Extract data

# Snout Length values
male_snout_len <- clean_data[    # Male snout length
    clean_data["sex"] == "M",
    "snout_vent_length_mm"]

female_snout_len <- clean_data[  # Female snout length
    clean_data["sex"] == "F",
    "snout_vent_length_mm"]

# Body Temps
f_gravid_btemp <- clean_data[     # Body temp of pregnant females
    clean_data["reproductive_status"] == "gravid",
    "body_temperature_c"]

f_nongravid_btemp <- clean_data[  # Body temp of non-pregnant females
    clean_data["reproductive_status"] == "nongravid",
    "body_temperature_c"]

Apply two sample bootstrap function to calculate mean

In order to compare these groups, a two-sample bootstrap approach is utilized. We resample the observed data with replacement 1000 times to construct a sampling distribution of the difference in means.

#Bootstrap estimate for mean Snout Lengths
boot_mean_snout_len <- two_sample_bootstrap(
    male_snout_len, 
    female_snout_len,
    iterations = 1000,
    stat = "mean")

print(head(boot_mean_snout_len, 5))
## [1] -4.172229 -4.938910 -4.247297 -4.503642 -4.307799
# Bootstrap estimate for mean Body temp of gravid and non-gravid females
boot_mean_body_temp <- two_sample_bootstrap(
    f_gravid_btemp, 
    f_nongravid_btemp,
    iterations = 1000,
    stat = "mean")

Generate Bootstrap Distribution Histogram and Comparative Statistics Table for Bootstrap estimate for mean Snout Lengths (Male vs Female)

The bootstrap distribution for snout-vent length visually represents the difference between males and females.

# Convert to dataframe
boot_mean_snout_len_dist <- data.frame(diff_len = boot_mean_snout_len)

#Plot bootstrap Distribution Histogram
ggplot(boot_mean_snout_len_dist, aes(x = diff_len))  +
    geom_histogram(bins = 30, fill = "lightblue", color = "black") +
    geom_vline(xintercept = mean(boot_mean_snout_len),
             color = "red", size = 1.2) +
  labs(
    title = "Bootstrap Distribution: Snouth length Difference (Male vs Female)",
    x = "Difference in Mean snout lengths (mm)",
    y = "Frequency"
  )

The bootstrap distribution for the difference in mean snout-vent length in males vs females is centered at approximately -4.5 mm. Since the entire distribution is well below zero, we can conclude that there is a statistically significant difference in the size of snout-vent lengths between the sexes in this population.

Generate Bootstrap Distribution Histogram and Comparative Statistics Table for Bootstrap estimate for mean Body temperatures (Gravid vs Non-Gravid)

The body temperature bootstrap distribution allows us to evaluate the thermoregulatory behavior of female lizards. The difference in means can be analyzed to infer whether reproductive status leads to changes in body temperature.

# Convert to dataframe
boot_mean_body_temp_dist <- data.frame(diff_temp = boot_mean_body_temp)

#Plot bootstrap Distribution Histogram
ggplot(boot_mean_body_temp_dist, aes(x = diff_temp))  +
    geom_histogram(bins = 30, fill = "darkblue", color = "black")+
    geom_vline(xintercept = mean(boot_mean_body_temp),
             color = "red", size = 1.2) +
  labs(
    title = "Bootstrap Distribution: Body Temperature Difference (Gravid vs Non-Gravid)",
    x = "Difference in Mean Body Temperature (Celsius)",
    y = "Frequency"
  )

 #Comparative Table
comparative_table_for_mean_body_temp <- data.frame(
  Statistic = c("Mean", "Median", "Standard Deviation"),
  Gravid = c(
    mean(f_gravid_btemp),
    median(f_gravid_btemp),
    sd(f_gravid_btemp)),
  Nongravid = c(
    mean(f_nongravid_btemp),
    median(f_nongravid_btemp),

  ))

# Print table

The comparison of body temperatures between gravid and non-gravid females shows a bootstrap distribution centered near -0.9°C. The large majority of the distribution is below zero and negative. This provides evidence to suggest that reproductive status does influence thermoregulation in this species.
